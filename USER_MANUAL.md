# User Manual

## Introduction

Welcome to our document management application! This application allows you to organize your documents and folders in a tree-like structure, with support for versioning and full-text search.

## Getting Started

1.  **Installation:**
    *   **Windows:** Run the provided installer (`.exe` file) and follow the on-screen instructions.
2.  **Launching the Application:**
    *   Once installed, you can launch the application from the Start Menu or by double-clicking the desktop shortcut.

## Features

### Tree View

The main window is divided into a tree view on the left and an editor on the right. The tree view displays your folders and documents in a hierarchical structure.

### Creating Folders and Documents

-   **Create a new folder:** Click the "New Folder" button at the top of the tree view. You will be prompted to enter a name for the folder.
-   **Create a new document:** Click the `+` icon next to a folder to create a new document inside that folder. You will be prompted to enter a name for the document.

### Editing Documents

1.  Select a document in the tree view to open it in the editor.
2.  Make your changes to the content in the editor.
3.  Click the "Save" button to save your changes. Each time you save, a new version of the document is created.

### Deleting Nodes

-   Click the `x` icon next to a folder or document to delete it. You will be asked to confirm the deletion. **Warning:** Deleting a folder will also delete all of its contents.

### Searching

-   Full-text search is supported by the backend, but the UI for searching is not yet implemented. This feature will be available in a future release.
